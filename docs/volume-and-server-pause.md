# Playback level

In Settings → Playback, enable loudness normalization and choose Normal, Louder or Maximum using the themed connected buttons. Normal preserves the existing target; Louder and Maximum raise it by 6 and 12 dB while retaining the measured peak ceiling. Unknown or invalid profiles receive no extra gain. The setting is saved on this phone and applies to the same player in Android Auto. Changes ramp smoothly during playback; original files and the existing PCM16 path remain unchanged.

## Manual check

Enable normalization in Settings → Playback and compare Normal, Louder and Maximum on the same measured track. The peak ceiling may limit the increase. Check phone playback and the same player in Android Auto. Files are never rewritten. Global server pause belongs to the web interface, not this app.
